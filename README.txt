葉隠 COMPASS v3

2026-08-30

主な変更:
- 「今月の返済を始める」返済モードを追加
- 支払い前に債権者名・今回予定額・支払期日を確認
- 「支払先・金額を確認した」操作後のみ支払完了記録が可能
- 支払完了で返済通帳・債務先残高・全体残高・進捗を自動更新
- 今月の完了件数、支払済み金額、予定残額を表示
- 各債務先カードに今月の「未払い／支払済み」状態を表示
- CSV（Excel / Numbers対応）とJSONバックアップを継続

注意:
- 葉隠Compass自体は送金を行いません。
- 実際の振込先、請求内容、金額は銀行アプリ・和解書・請求書で必ず照合してください。
- 口座番号や顧客番号などの機微情報はアプリ内に保存しない設計です。
