# 葉隠 COMPASS

返済計画と返済実績を、できるだけシンプルに管理するための個人用Webアプリです。

> 静かに、確実に、山を崩す。

## 現在のバージョン

**返済モード v4.8.5**  
更新日: 2026-10-01

## 主な機能

- 和解総額・累計返済額・現在残高・返済進捗率の表示
- 債務先ごとの今月予定額、支払済額、累計返済額、現在残高、終了予定の確認
- 振込前の支払先・金額・期日・振込先確認
- 支払完了後の返済通帳への記録
- 今月の完了件数、支払済額、予定残額の集計
- 返済履歴のブラウザ内保存
- JSONバックアップ／復元
- Excel / Numbers用CSV出力

## v4.8.5 の変更点

Numbersで実際の振込作業をしやすくするため、CSV出力を改善しました。

- 返済計画CSVの先頭に **「支払済」** 列を追加
- 振込先を **「振込先銀行」** と **「支店・口座情報」** に分離
- Numbersで銀行名をフィルターし、同じ銀行への振込をまとめて確認しやすくした
- 今月支払済みの債務先はCSV出力時に `✓` を表示
- 金額は文字列化せず数値として出力し、Numbers側で集計・3桁区切り表示ができる形を維持
- 返済計算、返済通帳、月次判定など既存の主要ロジックは変更なし

### Numbersでの運用例

1. 「Excel / Numbers用CSV」を出力
2. NumbersでCSVを開く
3. 「振込先銀行」でフィルター
4. 同じ銀行への振込を順番に処理
5. 「支払済」列を確認
6. 必要に応じてNumbers側で金額列を3桁区切り表示に設定

※ CSV自体にはNumbers固有のチェックボックス書式は保存されません。「支払済」列はCSV上では `✓` / 空欄です。

## データ保存について

返済履歴はブラウザの `localStorage` に保存されます。ブラウザのデータ消去や端末変更に備え、定期的に **バックアップJSON** を保存してください。

振込先情報は、アプリ上では口座番号の下4桁などマスクされた情報を表示し、銀行アプリに登録済みの振込先との照合に使用します。葉隠COMPASS自体から送金は行いません。
